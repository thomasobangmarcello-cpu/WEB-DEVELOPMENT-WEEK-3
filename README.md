
# Budget Tracker

## Week 3: Visual Design Challenge (CSS)

### Project Description

The Budget Tracker is a web application that helps users record and manage their daily expenses.

For Week 3, I improved the visual design of my existing Budget Tracker using CSS.

The aim was to create a clean, modern, professional and user-friendly interface without introducing new functionality.

### Technologies Used

- HTML5
- CSS3
- Google Fonts
- JavaScript (existing project functionality)

### Project Files

#### 1. index.html

Contains the structure of the Budget Tracker application.

It includes:
- Main page heading
- Add Expense form
- Expense table
- Connection to the stylesheet
- Connection to the existing JavaScript file

#### 2. style.css

Contains the visual styling of the application.

The CSS includes:

- Professional blue and white color palette
- Google Fonts integration
- Poppins font for headings
- DM Sans font for body text
- Styled form inputs and buttons
- Styled expense table
- Alternating table row colors
- Borders and rounded corners
- Margin and padding
- CSS Box Model
- Responsive design

#### 3. script.js

Contains the existing JavaScript functionality used to manage expenses.

### Color Palette

- Background: #F4F7FB
- Primary Blue: #2563EB
- Dark Heading: #172554
- Table Header: #1E3A8A
- Alternating Rows: #EFF6FF
- Borders: #E2E8F0
- Body Text: #475569

### Typography

Two Google Fonts were used:

- Poppins for headings
- DM Sans for body text and form elements

### CSS Box Model

The CSS Box Model was applied using:

- Margin to separate sections
- Padding to create internal spacing
- Borders to define containers
- Border-radius to create rounded corners

The heading, Add Expense form and Expense Table are displayed as separate cards.

### How to Run the Project

1. Download or clone the repository.
2. Open the project folder.
3. Open index.html in a web browser.
4. Use the existing Budget Tracker functionality.

### Conclusion

The Week 3 challenge improved the appearance and usability of my existing Budget Tracker through consistent colors, typography, form styling, table styling and effective use of the CSS Box Model.
